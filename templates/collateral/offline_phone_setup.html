  1. Open the downloaded decsi-field-ca.crt.

  3. Confirm install (phone may warn that it can monitor traffic — expected for a local CA).

iPhone

  1. Open the download in Safari → Install Profile.
  2. Settings → General → VPN & Device Management → install the DECSI profile.
  3. Settings → General → About → Certificate Trust Settings → enable full trust for DECSI Field Local CA.
