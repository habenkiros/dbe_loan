Tablet field checklist

Use this before leaving the branch and on site. GPS and camera need a secure page (HTTPS or localhost).

Checking this device…

1. This browser page

  • Host: {{ page_host }}
  • Server sees HTTPS: {% if page_is_secure %}yes{% else %}no (ok on http://localhost){% endif %}
  • HTTPS proxy mode: {% if https_proxy_enabled %}on{% else %}off — use HTTP on localhost, or start the HTTPS compose overlay for phones{% endif %}

2. Before leaving the branch (online)

  1. Open the app on the tablet via HTTPS (or http://localhost only on the laptop itself — phones need HTTPS).
  2. Accept the certificate warning once if using the local self-signed cert.
  3. Log in, open the loan → Field visit (or Summary).
  4. Tap Prepare offline so the loan is cached on this device.
  5. Optional: add the PWA to the home screen (browser menu → Install / Add to Home Screen).

3. On site (weak or no signal)

  1. Keep using the same tablet browser / installed PWA.
  2. Mark site GPS, take photos, enter BOQ / asset details — they queue on the device when offline.
  3. Do not expect final Submit collateral offline (policy and coverage stay online).

4. Back online

  1. Reconnect to branch Wi‑Fi or mobile data.
  2. Tap Sync now (or wait for auto-sync) until the pending badge clears.
  3. Finish review, then Submit collateral from Summary.

5. Ops: enable HTTPS for LAN tablets

On the server / laptop that runs Docker:

./scripts/gen_field_https_certs.sh docker compose -f docker-compose.yml -f docker-compose.https.yml up --build

Then open https://<this-machine-lan-ip>:8443 on the tablet. Laptop testing can stay on http://localhost:8000.
