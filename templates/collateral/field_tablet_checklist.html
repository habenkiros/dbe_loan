Download the loan pack on branch Wi‑Fi, work on site with no internet, sync when you return. GPS/camera still need HTTPS when you first install.

Checking this device…

The model (pack → work → sync)

  1. Download for offline caches this loan’s field steps + scripts on the phone.
  2. Install app (Add to Home Screen). On site open that icon only — do not type an IP.
  3. Captures queue on the phone. Back on PC Wi‑Fi, tap Sync now.

Not magic remote access: the phone cannot invent a path to a PC that is off the network. After download, the phone itself is the source of the pages.

Important: phone hotspot vs PC hotspot

  • Problem setup: phone hotspot → PC joins → you walk away with the phone. The PC drops and Chrome tries the dead IP.
  • Better: PC hotspot (or travel router); phone joins while downloading.
  • True offline test: After Download + Install, Airplane Mode → Home Screen app → loan still opens. If not, do not leave yet.

2. Before leaving the branch (on PC Wi‑Fi)

  1. Phone on same Wi‑Fi / hotspot as the PC.
  2. Open https://<pc-lan-ip>:8443, accept the certificate once.
  3. Log in → loan → Field visit.

  5. Install / Add to Home Screen (required).
  6. Airplane Mode test: open installed app → field visit still works.

3. On site

  1. Open the Home Screen app only (starts on Offline packs).
  2. Tap the prepared loan → field visit steps.
  3. Capture GPS/photos — they queue on the device.
  4. Final Submit collateral stays online after sync.

4. Back with the PC

  1. Reconnect phone to PC Wi‑Fi / hotspot.
  2. Auto-retry runs, or tap Sync now.
  3. Use Retry abandoned if needed, then submit from Summary.
