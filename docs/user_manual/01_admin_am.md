## 3. Hub Settings (የውቅረት ቅደም ተከተል)

```text
1. ወረዳዎች → ቅርንጫፎች → ዲፓርትመንቶች (HO)
2. ክልል → ዞን → ከተማ/ወረዳ
3. ተጠቃሚዎች (ሚና፣ ቅርንጫፍ/ወረዳ)
4. የብድር ምድቦች (ምርቶች)
5. የሰነድ አይነቶች
6. በምድብ የሰነድ ጥቅል
7. የፈቃድ ኮሚቴዎች
8. የዋስትና አይነቶች፣ ፖሊሲ፣ ግምት ውቅረት
9. ዲጂታል ማመልከቻ (መክፈት/መዝጋት፣ ክፍያ)
10. የኦንላይን ማመልከቻ ክትትል
```

> **Screenshot (H-19):** የዲጂታል ማመልከቻ ቅንብሮች።  
> **Screenshot (H-20):** የሰነድ ጥቅል በምድብ።

### 3.1 ጂኦግራፊ እና ድርጅት

ወረዳ/ቅርንጫፍ የሪፖርት እና የብድር እይታን ይገድባል። HO ተጠቃሚዎች ዲፓርትመንት ሊኖራቸው ይችላል።

### 3.2 ተጠቃሚዎች

የሰራተኛ መለያዎችን ይፍጠሩ — **ሚና**፣ **ቅርንጫፍ/ወረዳ**፣ አስፈላጊ ከሆነ **ዲፓርትመንት**።  
የደንበኛ መለያዎች እዚህ አይፈጠሩም — በዲጂታል ማመልከቻ ይመዘገባሉ።

### 3.3 የብድር ምድቦች እና ሰነዶች

1. **Loan categories** — ምርቶች።  
2. **Document types** — አጠቃላይ ካታሎግ።  
3. **Document pack** በእያንዳንዱ ምድብ — የግዴታ/አማራጭ እና ቅደም ተከተል።

### 3.4 ኮሚቴዎች እና ዋስትና

**Approval committees** — የድምጽ አባላት እና ደረጃዎች።  
**Collateral policy / Estimation config** — ማን ዋስትና እንደሚገመግም (LO / ኢንጂነሪንግ / ሁለቱም)።  
**Unlock queue** — ከተቆለፈ በኋላ ማረም።

### 3.5 ዲጂታል ማመልከቻ

| ቁጥጥር | ውጤት |
|--------|--------|
| መክፈት/መዝጋት | ሲዘጋ ደንበኞች “temporarily closed” ያያሉ |
| የማቀናበሪያ ክፍያ (ብር) | ከማስገባት በፊት |
| የይለፍ ቃል / lockout | የደንበኛ ደህንነት |
| የCBS ማረጋገጫ | አማራጭ የደንበኛ ቁጥር ማረጋገጥ |
| Chapa | ህያው ወይም mock |
