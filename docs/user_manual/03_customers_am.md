# የደንበኛ መመሪያ — ዲጂታል ማመልከቻ (Digital Apply)

**ለማን ነው:** በኦንላይን ብድር ማመልከት የሚፈልጉ የDECSI ደንበኞች።  
**መግቢያ:** ዲጂታል ማመልከቻ በ `/`  
**እንግሊዘኛው መመሪያ:** [03_customers.md](03_customers.md)

---

## 1. ዲጂታል ማመልከቻ ምን ያደርጋል?

በዚህ ፖርታል፦

1. በ**የDECSI ደንበኛ ቁጥር** እና በሞባይል ስልክ መለያ ይፈጥራሉ።  
2. የብድር ማመልከቻ ይጀምራሉ (ምርት፣ ቅርንጫፍ፣ መጠን፣ ዓላማ)።  
3. ለዚያ ምርት የሚያስፈልጉ **ሰነዶችን** ይሰቀላሉ።  
4. የ**ማቀናበሪያ ክፍያ** (processing fee) በኦንላይን ይከፍላሉ።  
5. ካስገቡ በኋላ **የተራ ቁጥር / Queue ID** (ለምሳሌ `HK-000000001`) ያገኛሉ።  
6. እስከ ክፍያ/ውሳኔ ድረስ ሁኔታውን ይከታተላሉ።

**“Digital apply is temporarily closed”** ካዩ፣ ፖርታሉ ለጊዜው ዝግ ነው — ቅርንጫፍዎን ይጎብኙ ወይም በኋላ ይሞክሩ።

---

## 2. መለያ መፍጠር

1. የዲጂታል ማመልከቻ መነሻ ገጽ ይክፈቱ።  
2. **Create account** ይምረጡ።  
3. ያስገቡ፦  
   - የDECSI **ደንበኛ ቁጥር**  
   - ሙሉ ስም  
   - የሞባይል ቁጥር  
   - የይለፍ ቃል (በገጹ ላይ ያሉትን ህጎች ይከተሉ)  
   - የውል ሁኔታ ካለ ይቀበሉ  
4. ምዝገባውን ያስገቡ።

> **Screenshot (C-01):** የዲጂታል ማመልከቻ መነሻ — መለያ መፍጠር ወይም መግባት።  
> **Screenshot (C-02):** ምዝገባ — የደንበኛ ቁጥር፣ ስም፣ ሞባይል፣ የይለፍ ቃል።

አንዳንድ ጊዜ የደንበኛ ቁጥር ከDECSI መዝገብ ጋር ይረጋገጣል። ካልተሳካ ከቅርንጫፍዎ ጋር ቁጥሩን ያረጋግጡ።

### አስቀድመው ተመዝግበዋል?

**I already have an account** ይምረጡ፤ በ**ሞባይል** ወይም በ**ደንበኛ ቁጥር** እና በይለፍ ቃል ይግቡ።

---

## 3. መግባት፣ የይለፍ ቃል እርዳታ እና ደህንነት

| ተግባር | እንዴት |
|------|--------|
| መግባት | `/login/` — ስልክ ወይም ደንበኛ ቁጥር + የይለፍ ቃል |
| መውጣት | ከሜኑ Logout |
| የይለፍ ቃል ረሱ | Forgot password → ወደ ስልክዎ OTP → አዲስ የይለፍ ቃል |
| የይለፍ ቃል መቀየር | ከመለያ ገጽ — change password |

- ጠንካራ የይለፍ ቃል ይጠቀሙ።  
- ለOTP ስልክዎን ዝግጁ ያድርጉ።  
- ብዙ ጊዜ ስህተት ከገቡ መለያ ለጊዜው ሊቆልፍ ይችላል።

---

## 4. ብድር ማመልከት (ደረጃ በደረጃ)

ከ**My applications** / መነሻ አዲስ ማመልከቻ ይጀምሩ። አራት ደረጃዎች አሉ፦

**1 · ዝርዝር → 2 · ሰነዶች → 3 · ክፍያ → 4 · ማስገባት**

### ደረጃ 1 — ዝርዝር (Details)

1. የብድር **ምርት** ይምረጡ።  
2. **ቅርንጫፍ** ይምረጡ።  
3. **መጠን**፣ **ዓላማ** እና ካለ የዋስትና አይነት ያስገቡ።  
4. ያስቀምጡና ይቀጥሉ።

እስከማስገባት ድረስ ረቂቁን (draft) ትተው በኋላ መመለስ ይችላሉ።

### ደረጃ 2 — ሰነዶች (Documents)

1. ለምርቱ የተዘረዘሩ ሰነዶችን ይሰቀሉ።  
2. የግዴታ ሰነዶች ሳይሟሉ ማለፍ አይቻልም።  
3. ግልጽ ስካን/ፎቶ ይጠቀሙ።

### ደረጃ 3 — የማቀናበሪያ ክፍያ (Fee)

1. የክፍያ መጠኑን (ብር) ያረጋግጡ።  
2. ክፍያውን ይጀምሩ (Chapa ወይም በገጹ የሚታየው)።  
3. እስከማረጋገጫ ድረስ አሳሹን አይዝጉ።

ክፍያ ካልተሳካ ከFee ደረጃ እንደገና ይሞክሩ፤ ጊዜውን ከቅርንጫፍ ጋር ይጋሩ።

### ደረጃ 4 — ማስገባት (Submit)

1. ዝርዝርና ሰነዶችን ይገምግሙ።  
2. Submit ያረጋግጡ።  
3. **Queue ID** ወዲያውኑ ያስቀምጡ / ይቅረጹ።

ረቂቅ (ያልገባ) ማመልከቻን ማቋረጥ ከተፈቀደ በገጹ ላይ ይታያል። የገባ ማመልከቻ ለቅርንጫፍ ነው — ለመሰረዝ ቅርንጫፍዎን ያነጋግሩ።

---

## 5. ሁኔታ መከታተል

ከ**My applications** ማመልከቻዎን ይክፈቱ።

### ረቂቅ ሳለ

ደረጃዎች፦ ዝርዝር → ሰነዶች → ክፍያ → ማስገባት። Queue ID ለማግኘት እስከ ማስገባት ይድረሱ።

### ካስገቡ በኋላ

| ደረጃ | ትርጉም |
|------|--------|
| **Submitted** | በኦንላይን ተቀብሏል፤ በቅርንጫፍ ተራ ላይ ነው |
| **Branch intake** | የቅርንጫፍ ኮኦፕሬቲቭ እየገመገመ ነው |
| **Loan processing** | ባለሙያ ሰነድ፣ ዋስትና እና ትንተና እያደረገ ነው |
| **Credit decision** | የብድር ውሳኔ ሂደት ላይ ነው |
| **Disbursement prep** | የተፈቀደ ብድር ለክፍያ እየተዘጋጀ ነው |
| **Disbursed** | ገንዘቡ ተከፍሏል |

| ውጤት | ትርጉም |
|------|--------|
| **Not approved / Declined** | አልፈቀዱም — ዝርዝር ለቅርንጫፍ |
| **Closed / Rejected** | ያለ ፈቃድ ተዘግቷል |
| **Cancelled** | ረቂቁ ከማስገባት በፊት ተሰርዟል |

ስልክ ሲደውሉ ወይም ቅርንጫፍ ሲሄዱ **Queue ID** ይጠቀሙ።

---

## 6. ካስገቡ በኋላ ምን ይሆናል?

የብድር ትንተናና የዋስትና ግምገማ በኦንላይን አያጠናቅቁም። የDECSI ሰራተኞች ሰነድ ማረጋገጥ፣ ትንተና፣ ኮሚቴ እና ክፍያን ይቀጥላሉ። ጊዜው በምርት፣ በሰነድ ሙሉነት እና በኮሚቴ መርሃ ግብር ይለያያል።

---

## 7. ለስኬታማ ማመልከቻ

- ትክክለኛ **ደንበኛ ቁጥር** ይጠቀሙ።  
- የሚያገለግልዎትን **ቅርንጫፍ** ይምረጡ።  
- ከክፍያ በፊት **ሁሉንም የግዴታ ሰነዶች** ይስቀሉ።  
- የክፍያ ማረጋገጫ እና **Queue ID** ይያዙ።  
- ቅርንጫፍ ተጨማሪ ሰነድ ወይም ጉብኝት ካለፈለገ በፍጥነት ምላሽ ይስጡ።  
- የይለፍ ቃልዎን ወይም OTPን ለማንም አይስጡ።

## 8. ችግር መፍታት

| መመዝገብ አልተቻለም | ደንበኛ ቁጥርና ስልክ ያረጋግጡ |
| OTP አልመጣም | ስልክ ያረጋግጡ፤ እንደገና ይሞክሩ፤ ካልሆነ ቅርንጫፍ |

| Queue ID የለም | አሁንም ረቂቅ ነው — Fee እና Submit ያጠናቅቁ |
| ሁኔታ አይንቀሳቀስም | ብዙ ጊዜ ብዙ ቀናት ሊፈጅ ይችላል፤ አስቸኳይ ከሆነ በQueue ID ቅርንጫፍ ያነጋግሩ |
